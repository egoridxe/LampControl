# Lamp Control

Десктопное приложение для Windows (Python + CustomTkinter + Bleak) для управления Bluetooth Low Energy (BLE) RGB-лампами и светодиодными лентами семейства **FINDN / MR Star / SymphonyLight** (`GATT--DEMO` / `GATT-DEMO`) в минималистичном стиле **Google Material Design 3** со светлой и тёмной темами.

## Быстрый запуск (`.exe`)

Скачайте и запустите готовый [`LampControl.exe`](LampControl.exe) — установка Python не требуется.  
Чтобы добавить ярлык в меню «Пуск» (в раздел *«Недавно добавленные»*), выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\register_start_menu.ps1
```

## Возможности

- **Управление по BLE напрямую с ПК** (без телефона и без геолокации):
  - Автопоиск ламп (`GATT--DEMO`, `GATT-DEMO`, `MR STAR`, `SYMPHONY`, сервис `0000fff0` / `00002022`, характеристика записи `0000fff3`) и фильтр «Все BLE» для нестандартных имён.
  - Постоянное соединение с троттлингом команд и автоподключением.
- **Цвет и яркость**:
  - Интерактивное HSV-цветовое колесо, пресеты оттенков белого (*Тёплый / Нейтральный / Холодный*), 6 сохраняемых слотов (ПКМ — сохранить цвет), базовая палитра.
  - Настройка количества светодиодов (**точек**, `8–300`).
- **Режимы анимаций (`1–117`)**:
  - Категории (*Базовый*, *Открытие и закрытие*, *Переход*, *Бегущая вода*, *Шлейф*, *Бег*, *Все 1–117*), переключатель направления `P`, скорость и яркость.
- **Светомузыка и Амбилайт экрана**:
  - Захват системного звука Windows через **WASAPI Loopback** (`PyAudioWPatch`) или микрофона ПК (режимы *Энергия (Бас)*, *Спектр*, *Бит-строб*).
  - **Амбилайт экрана** — подстраивает цвет лампы под доминирующий цвет монитора.
- **Микрофон лампы и Расписание**:
  - Управление встроенным датчиком звука контроллера, синхронизация часов лампы, аппаратный таймер и таймер сна на ПК.
- **Светлая и тёмная темы Material 3** + панель **Настройки и диагностика BLE** (переключатели совместимости прошивки, RAW hex-команды, лог пакетов).

## Запуск из исходников и пересборка `.exe`

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Сборка `.exe`:

```powershell
powershell -ExecutionPolicy Bypass -File .\build_exe.ps1
```
